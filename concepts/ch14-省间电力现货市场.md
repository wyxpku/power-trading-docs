# 省间电力现货市场

## 核心论点

省间电力现货市场是中国「统一市场、两级运作」架构的省间层，解决跨省跨区的电能余缺互济和大范围资源配置问题。在落实中长期交易的基础上，各省市场主体通过竞价把富余电力跨省卖出或购入，出清机制以「价差优先成交 + 边际电价结算 + 路径折算」为特征。

## 建设基础

- **资源禀赋与负荷逆向分布**：90% 煤炭、85% 太阳能、80% 风能在西部和「三北」，70% 用电负荷在中东部
- **大电网互联基本形成**：跨区直流 29 回（特高压直流 14 回），跨省跨区输送能力达 270GW
- **跨区现货交易（2017）为前身**：仅可再生能源参与，询价模式，角色固定

## 从跨区现货到省间现货的六大升级

| 维度 | 跨区现货（2017） | 省间现货（2021） |
|------|------------------|------------------|
| 交易范围 | 跨区域省间 | 所有省间 |
| 市场主体 | 仅可再生能源 | 可再生能源 + 火电 + 核电 |
| 日内频次 | 5 次/日 | 12 次/日 |
| 定价模式 | 询价（报量不报价） | 竞价（报量报价） |
| 购售角色 | 同一天固定 | 不同时段可切换 |
| 绿色属性 | 无 | 支持标记，为绿电交易铺路 |

## 出清与定价机制（核心）

1. **价差驱动成交**：对每对买卖方，沿可行路径计算有效价差 = 买方报价 - 卖方报价 - 输电成本（含输电费和网损）。按价差从大到小依次成交，直到通道用完或价差归零
2. **输电权隐式拍卖**：同一买卖方优先用低成本路径；不同买卖方按报价高低竞争通道使用权
3. **边际电价结算**：卖方节点最后一笔成交的买卖双方报价平均值 = 该节点结算价；沿路径反向折算（加输电费和网损）得到买方节点结算价

## 衔接逻辑

| 时序 | 内容 |
|------|------|
| D-2 日 | 国调下发中长期联络线预计划，作为省内预出清边界 |
| 省内预出清 | 确定各省余缺需求 |
| 省间日前 | 国调组织省间现货交易，出清结果叠加中长期曲线，作为省内正式出清新边界 |
| 日内 | 省间日内现货（12 次/日，每 2h）+ 区域辅助服务 |
| 实时 | 省内实时市场出清 |

关键设计：省间结果原则上不随实际发用电变化（直流通道要稳），偏差优先在省内市场解决。
