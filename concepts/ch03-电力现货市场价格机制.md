# 第3章 电力现货市场价格机制

## Core Claim

电力现货市场价格机制由"报价→出清→结算"三环管道构成。出清价格形成机制（SMP/ZMP/LMP）按电网阻塞精细度递进选择；结算采用边际统一价（MCP）激励诚实报价；中长期合同在全电量竞价下作为差价合约"只管结算"——物理层（调度优化）与金融层（价格对冲）彻底分离。LMP 是集中式市场的标志性工具，把发电成本+阻塞+网损翻译为节点价格信号。

## Key Concepts

### 1. 价格形成三环管道
```
报价方式（怎么报）→ 出清价格（怎么算价）→ 结算价格（怎么付钱）
```
- 报价：单边/双边/混合；报量报价 vs 报量不报价；全电量竞价 vs 部分电量竞价
- 出清：SMP / ZMP / LMP（见下）
- 结算：MCP（统一边际价）vs PAB（按报价）

### 2. 出清价格三机制（选择依据 = 阻塞程度）
| 机制 | 粒度 | 适用条件 | 典型市场 |
|---|---|---|---|
| SMP | 全网一价 | 无/轻微阻塞 | 早期英国Pool |
| ZMP | 分区一价 | 阻塞集中在特定断面 | 欧洲统一市场 |
| LMP | 每节点一价 | 阻塞严重普遍 | 美国PJM/ERCOT |

- LMP = 边际发电成本 + 阻塞成本 + 网损
- 无阻塞时三者相等；阻塞是唯一的价格分化器
- 中国集中式试点省份（山西/山东/广东/福建等）倾向采用 LMP

### 3. 全电量竞价与差价合约（集中式核心机制）
- **全电量竞价**：所有电量进现货市场，调度看全报价选最便宜组合
- **差价合约**：中长期合同纯财务对冲，不影响申报/出清/调度，只在结算时算差价
  - 结算 = (合同价 - 现货价) × 合同量，多退少补
  - 无论现货价如何，合同量部分实际到手 = 合同价
- 合同 = "价格保险"，不是"提货单"

### 4. 边际定价 vs 平均价（MCP 的激励逻辑）
- 边际定价：出清价 = 最后满足负荷的机组报价，所有中标机组拿同价
- 激励诚实报价：机组报价只决定"能不能中标"，不决定"拿多少钱"
- 若用平均价：贵机组亏损→虚报高价→价格螺旋上升→市场崩坏

### 5. 结算：MCP vs PAB
- MCP（统一边际价）：激励按真实成本报价，对中小机组友好，但可能被市场力滥用（持留容量）
- PAB（按报价）：防过度支付，但鼓励虚报、不利于中小机组
- 中国过渡期采用 MCP

### 6. 价格帽
- 会计成本法（中国，上下限，约均价3倍）vs 机会成本法/VOLL（国外，仅上限，可达均价数十倍）
- 稀缺定价机制（得州9000美元/MWh）

### 7. 网损处理（回应用户之前的提问）
- 三种分摊：平均网损分摊法 / 边际网损系数法 / 潮流增量法
- **中国：网损含在输配电价中回收，不需额外分摊**
- 集中式可事前/实时计算网损率；分散式事后分时计算

## Implications

- 物理层（调度优化）与金融层（价格对冲）彻底分离是集中式市场的设计精髓
- LMP 是把物理约束翻译成经济语言的核心工具
- 边际定价 + 统一结算是市场效率的基石，但依赖充分竞争
- 容量市场/容量补偿解决"贵机组不发电但固定成本需回收"的问题
