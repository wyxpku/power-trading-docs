# 第6章 电力现货市场绩效评价

## Core Claim

绩效评价是市场的"打分卡"。SCP模型（结构→行为→绩效）提供评估逻辑：市场集中度决定行为，行为决定绩效。我国采用"安全/公平/绿色/高效"四维评价框架，每一个维度都对应前五章学过的机制。本章是Cluster 1的收尾——构成"建市场→管市场→评市场"的完整闭环。

## Key Concepts

### 1. SCP模型（评估的底层逻辑）
```
市场结构(Structure) → 市场行为(Conduct) → 市场绩效(Performance)
  集中度、壁垒        报价策略、持留       价格水平、效率
```
- 结构决定行为，行为决定绩效
- 改绩效要从改结构入手（如拆分大厂商降低HHI）
- 连接ch05市场力监测：先看结构(HHI)→再看行为(持留/虚报)→最后看绩效(价格扭曲)

### 2. 四维评价框架
| 维度 | 评什么 | 连接前章 |
|---|---|---|
| 安全 | 电网安全边界 | ch04阻塞管理 |
| 公平 | 市场力、信息披露 | ch05风险管控 |
| 绿色 | 清洁能源消纳、减排 | 新能源参与比例 |
| 高效 | 参与度、价格信号 | ch03 LMP价格信号 |

### 3. 设计5原则（扫描即可）
相关性、重要性、系统性、科学性、实用性

### 4. 评价方法
- SCP模型：定性框架
- AHP层次分析法：定量权重计算（两两比较确定权重）
- 两者结合使用

## Cluster 1 完整闭环
```
市场是什么（ch1概述）
  → 谁来运营（ch2组织）
  → 价格怎么定（ch3价格机制）
  → 物理瓶颈怎么处理（ch4阻塞管理）
  → 出事了怎么防（ch5风险管控）
  → 跑得好不好怎么评（ch6绩效评价）
```

- 安全维度 ↔ ch04阻塞管理
