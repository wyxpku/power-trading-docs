# 第5章 电力市场信息披露与风险管控

## Core Claim

本章是市场的"免疫系统"——信息披露是阳光（事前透明），风险管控是防护网（事中事后应对）。七种风险全部连回前四章的机制，防护工具组合成网。价格帽是防范市场力的最后一道硬约束防线。容量成本回收机制（稀缺定价/容量市场/容量补偿）解决贵机组固定成本回收问题，中国现阶段建议从容量补偿起步。

## Key Concepts

### 1. 信息披露四层透明度
| 层级 | 谁看 | 举例 |
|---|---|---|
| 公众信息 | 全社会 | 政策文件 |
| 公开信息 | 所有市场成员 | 出清结果、系统负荷 |
| 私有信息 | 仅自己 | 报价曲线、结算单 |
| 依申请披露 | 审核后特定人 | 完整电网模型 |

- 报价曲线必须保密（防信息驱动市场力），出清结果必须公开（自证公平）
- 过程透明，策略保密

### 2. 七种风险 ↔ 前四章防护工具
| 风险 | 防护工具 |
|---|---|
| 市场力风险 | 价格帽、HHI监测、拆分大厂商 |
| 价格波动风险 | 价格帽、金融衍生品(差价合约/FTR) |
| 长期供应安全 | 容量市场/容量补偿/稀缺定价 |
| 电网安全风险 | 安全校核、LMP阻塞信号 |
| 短期供应风险 | 应急调度、省间互济 |
| 信用风险 | 履约保函、信用评价 |
| 合规风险 | 标准体系、全程可追溯 |

### 3. 市场力防范三层防线
- 第一层：结构性防范（准入/拆分/限份额）—不让市场力产生
- 第二层：行为监测（HHI/量价指数）—发现市场力使用
- **第三层：价格帽**—最后一道硬约束，即使前两层失效，价格不超上限

### 4. 容量成本回收三机制
| 机制 | 做法 | 适用 | 典型 |
|---|---|---|---|
| 稀缺定价 | 极高价格帽，靠尖峰回收 | 市场成熟 | 得州/澳洲 |
| 容量市场 | 竞拍容量价格 | 电能量市场完善 | 美国PJM |
| 容量补偿 | 政府核定容量电价 | **市场初期（中国）** | 山东99.1元 |

## Implications

- 信息披露是市场公平运行的基石，"过程透明+策略保密"平衡了公平与竞争
- 七种风险防护工具是前面四章机制的"编网"整合
- 价格帽是市场力的最后兜底，缺失会导致加州式危机
- 中国选择容量补偿而非容量市场，符合市场初期国情
