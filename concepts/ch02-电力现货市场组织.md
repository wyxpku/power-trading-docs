# 第2章 电力现货市场组织

## Core Claim

电力现货市场的组织架构是市场模式的必然产物：集中式市场天然要求调度交易合一（ISO/RTO），分散式市场天然趋向调度交易分设。中国采用"调度机构运营现货+交易机构负责准入结算"的分工，调度机构承担运营主体角色。现货市场本质是经济调度的市场化升级——底层优化机理一致，但引入供需两侧竞价。

## Key Concepts

1. **市场运营机构两种设置方式**
   - 合一（美国ISO/RTO）↔ 集中式市场；分设（英国/欧洲）↔ 分散式市场
   - 不是巧合：集中式需全电量联合出清，天然要求合一；分散式只调偏差，可分设

2. **中国职责分工**
   - 调度机构：组织交易、出清、安全校核、调度计划、技术支持系统、应急处置
   - 交易机构：主体准入、出具结算依据、信息披露
   - 记忆钩子："调度管出清和安全，交易管准入和结算"
   - 三级调度：国调→网调→省调，对应省间市场+省级市场

3. **调度模式演进史**
   - 经济调度（成本最低）→ 三公调度（公平）→ 节能调度（环保）→ 现货市场（供需两侧）
   - 现货市场与经济调度底层机理一致（都最小化成本），区别在于引入需求侧+市场化竞价
   - 新难题：市场力和价格操纵（ch05伏笔）

4. **市场运营与电网运行的关系**
   - 集中式：运营与安全责任统一（同一主体出清+校核）
   - 分散式：决策权与安全责任分裂（合同方决策只顾效益，调度只能事后平衡）— 这是分散式要求电网坚强的根因

5. **建设步骤**（程序性，扫描即可）：市场筹备→编制建设方案→编制规则体系→模拟/调电试运行→结算试运行→正式运行

6. **配套措施**（四类）：机制保障、制度保障、技术保障、组织保障

## Implications

- 组织架构选择不是独立的，必须与市场模式匹配
- 中国选择调度机构作为运营主体，体现了"安全第一"原则和对电网物理特性的尊重
- 现货市场的市场化带来新的监管挑战（市场力、价格操纵）
