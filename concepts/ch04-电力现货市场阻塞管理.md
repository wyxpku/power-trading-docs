# 第4章 电力现货市场阻塞管理

## Core Claim

阻塞管理是第3章 LMP/ZMP/SMP 的应用版——把物理瓶颈翻译成经济信号。四种方法本质是两种范式：定价法（LMP/ZMP，阻塞藏进价格差，集中式用）vs 修正法（再调度/对销交易，事后补救+附加费，分散式用）。阻塞盈余=负荷侧支付-发电侧收入，它持续偏高是"该扩建线路了"的投资信号。

## Key Concepts

### 1. 四种方法 = 两种范式

| 范式 | 方法 | 怎么处理 | 适用市场 |
|---|---|---|---|
| **定价法** | 市场分裂法(ZMP) | 阻塞断面切价区，各区独立出清 | 集中式，阻塞集中在固定断面 |
| **定价法** | 节点电价法(LMP) | 出清时编入所有线路约束，每节点一价 | 集中式，阻塞普遍复杂 |
| **修正法** | 再调度法 | 先无约束出清，事后限上/限下调整 | 分散式（英国Pool） |
| **修正法** | 对销交易法 | 平衡市场同时买入卖出 | 分散式（北欧） |

### 2. 阻塞盈余 = 钱流的核心

```
负荷侧总支付（按负荷节点高LMP）− 发电侧总收入（按发电节点低LMP）= 阻塞盈余
```

- 阻塞盈余被市场运营机构收走，**不是发电厂的利润**
- 用途：返还用户 / 投资输电网 / 通过FTR分配
- 最佳策略：用阻塞盈余的位置信息定向投资瓶颈线路（治本）

### 3. LMP 为什么按边际而非平均定价
- 节点3的LMP = 该节点增加1MW负荷的边际成本（=本地最贵机组的报价）
- 不按"实际供电机组的平均成本"——否则贵机组亏钱退出→缺电
- 边际定价保证所有机组至少覆盖成本，系统可持续

### 4. 中国实践
- 山西/山东/浙江/广东：LMP
- 福建：LMP但阻塞受限机组不作边际机组
- 甘肃：ZMP
- 四川：SMP+日前考虑网络约束

### 5. 阻塞盈余信号 → 输电网规划
- 持续高阻塞盈余 = 结构性瓶颈 = 该断面优先扩建
- 价格信号引导投资方向，减少规划盲目性

## Implications

- 阻塞管理的本质是"把物理瓶颈翻译成经济信号"
- 定价法 vs 修正法的选择映射集中式 vs 分散式市场模式
- 阻塞盈余既是"问题的症状"也是"解决问题的资金来源"
